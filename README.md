# Many Dice

Roll many d20s at once, with threat confirmations and paired rolls. Built with React, TypeScript and [Vite](https://vite.dev).

Live at [highdynamics.github.io/many-dice](https://highdynamics.github.io/many-dice/).

## Scripts

- `npm start` (or `npm run dev`): runs the app in development at [http://localhost:5173/many-dice/](http://localhost:5173/many-dice/).
- `npm test`: runs the tests once with [Vitest](https://vitest.dev).
- `npm run typecheck`: type-checks the project with `tsc --noEmit`.
- `npm run build`: type-checks, then builds the app into `dist`.
- `npm run preview`: serves the built app at its production path.
- `npm run deploy`: builds the app and publishes `dist` to the `gh-pages` branch.
